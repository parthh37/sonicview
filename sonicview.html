Nothing is uploaded. Only this page reads the file, and its security policy makes the browser block every network request. No account, no analytics.

Where do I get the .exp file?

Sign in to the SonicWall's web interface and use Export Settings:

  • SonicOS 5.x: System › Settings
  • SonicOS 6.x: Manage › Firmware & Settings

SonicView reads the classic SonicOS .exp format and was tested with SonicOS 5.8. Treat the file like a password: it holds your network layout, rules and encrypted credentials.
